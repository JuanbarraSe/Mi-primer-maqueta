Especificidad en CSS

Aprendiendo selectores y prioridades

¿Qué es la especificidad?

Es la forma en que el navegador resuelve los conflictos cuando varias reglas CSS afectan al mismo elemento. Decide cuál es más relevante y, por lo tanto, cuál se aplica.

¿Cómo funciona?

CSS se lee de arriba hacia abajo. Si encuentra un valor que no puede analizar, no se detiene ni muestra error: simplemente lo ignora.

Cuando dos reglas chocan, el navegador toma el último valor escrito. Pero si tienen distinta importancia, calcula un puntaje: cuanto más específico es el selector, más probabilidad tiene de aplicarse.

Puntaje de cada selector

Tipo Ejemplo Puntaje
!important color: red !important; 1, 0, 0, 0, 0
Estilo en línea style="color: red" 0, 1, 0, 0, 0
ID #identificador 0, 0, 1, 0, 0
Clase, atributo o pseudo clase .texto, :hover 0, 0, 0, 1, 0
Elemento p, button 0, 0, 0, 0, 1
Selector universal * 0, 0, 0, 0, 0
  • !important reescribe casi cualquier estilo. Evítalo o úsalo con mucha precaución.
  • Estilos en línea se imponen aunque el elemento ya tenga clases o IDs.
  • ID pesa más que las clases y las etiquetas, pero al ser único conviene usarlo más para funcionalidad que para estilos.
  • Clases son lo mejor para dar estilos; con una metodología como BEM mantienen la especificidad bajo control.
  • Elementos son los más básicos y los más fáciles de reescribir.
  • Selector universal no pesa nada: cualquier otra regla lo sobrescribe.

Ejemplos de especificidad

Selector universal

* → 0, 0, 0, 0, 0

Selector de clase

.texto → 0, 0, 0, 1, 0

Selector ID

#identificador → 0, 0, 1, 0, 0

Combinación de selectores

#prioridad + .especial + p → 0, 0, 1, 1, 1

Estilo en línea

style="" → 0, 1, 0, 0, 0 .boton (0, 0, 0, 1, 0) le gana a button (0, 0, 0, 0, 1) aunque la de elemento esté escrita después.

Suma de puntajes

Si una regla combina varios selectores, sus puntajes se suman y la regla se vuelve más específica. 

p                    → 0, 0, 0, 0, 1
    p.especial           → 0, 0, 0, 1, 1
    p.especial#prioridad → 0, 0, 1, 1, 1

Algunos consejos

  • Busca el balance: tu CSS debe ser lo bastante específico para que se aplique y lo bastante general para poder sobrescribirlo.
  • Evita los selectores demasiado específicos: dificultan la lectura y cambiar el código después.
  • Comenta y organiza tu código.
  • Usa una metodología como BEM. No existe una forma 100% correcta de escribir CSS.
