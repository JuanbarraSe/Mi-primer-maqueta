Modelo de caja (Box Model)

Aprendiendo a controlar los espacios y tamaños en CSS

¿Qué es el Box Model?

El Box Model o modelo de caja es un concepto fundamental de CSS que explica cómo se organizan y se muestran los elementos en una página web. Cada elemento HTML se representa como una caja rectangular que contiene diferentes espacios.

Permite controlar el tamaño, los bordes y la separación de los elementos para crear diseños más organizados.

¿Cómo funciona?

Cada elemento de una página web está formado por cuatro partes: contenido, padding, border y margin.

Estas partes trabajan juntas para determinar el espacio total que ocupa un elemento dentro de la página.

Al modificar sus valores en CSS podemos cambiar la distancia entre elementos, el tamaño de las cajas y su apariencia.

Partes del modelo de caja

Parte Descripción Ejemplo CSS
Content Es el contenido del elemento, como texto o imágenes. width: 200px;
Padding Es el espacio interno entre el contenido y el borde. padding: 20px;
Border Es el borde que rodea el contenido y el padding. border: 5px solid black;
Margin Es el espacio externo que separa una caja de otras. margin: 15px;

Ejemplo de Box Model

Este es un ejemplo de una caja creada con CSS:

.caja {
    width: 200px;
    height: 100px;
    padding: 20px;
    border: 5px solid black;
    margin: 15px;
}

¿Qué significa?

  • Width: establece el ancho del contenido.
  • Height: establece la altura del contenido.
  • Padding: agrega espacio interno.
  • Border: establece el borde de la caja.
  • Margin: agrega espacio externo.

Propiedad Box Sizing

La propiedad box-sizing permite controlar cómo se calcula el tamaño total de una caja.

Content-box

Es el valor predeterminado. El padding y el border se suman al ancho y alto establecidos. 

box-sizing: content-box;
Border-box

Incluye el padding y el border dentro del ancho y alto establecidos, facilitando el diseño. 

box-sizing: border-box;

Algunos consejos

  • Utiliza padding para separar el contenido de los bordes.
  • Usa margin para crear espacios entre diferentes elementos.
  • Define bordes cuando quieras resaltar o delimitar una caja.
  • Utiliza box-sizing: border-box para facilitar el control de los tamaños.
  • Organiza los espacios para que tu página sea más ordenada y adaptable.
