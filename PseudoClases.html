Pseudo Clases y Pseudo Elementos

Cambia el estilo según el estado de un elemento o modifica partes específicas de él, sin escribir HTML extra.

¿Qué es una pseudo clase?

Es una palabra clave que se agrega a un selector para aplicar estilos solo cuando el elemento está en un estado especial: con el mouse encima, seleccionado, deshabilitado, primero de una lista, etc.

Se escriben con dos puntos (:).

boton:hover {
    background-color: green;
}

¿Qué es un pseudo elemento?

Permite dar estilo a una parte específica de un elemento (la primera letra, la primera línea) o incluso crear contenido antes o después de él.

Se escriben con doble dos puntos (::).

p::first-letter {
    font-size: 3rem;
    color: blue;
}

Pseudo clases del mouse y el teclado

  • :hover el mouse está encima del elemento.
  • :active el elemento se está presionando (mientras haces clic).
  • :focus el elemento está seleccionado, por ejemplo un campo de texto.
  • :focus-visible recibe el foco con el teclado (tecla Tab).
  • :visited un enlace que ya se visitó.

Pruébalo: pasa el mouse, haz clic o usa Tab

.demo-btn:hover  { color: verde; }
.demo-btn:active { transform: scale(.94); }

Pseudo clases estructurales

Eligen elementos según su posición dentro de su contenedor.

  • Primer elemento
  • Segundo elemento
  • Tercer elemento
  • Cuarto elemento
  • Último elemento
li:first-child      { ... }
li:last-child       { ... }
li:nth-child(even)  { ... }

Pseudo clases de formularios

Cambian el estilo según el estado de un campo: seleccionado, marcado, bloqueado o con datos correctos. 

input:focus    { border-color: blue; }
input:disabled { background: gray; }
input:checked + span { color: green; }

Pseudo elementos en acción

::first-letter

CSS permite darle estilo solo a la primera letra de un párrafo, como en los libros y las revistas.

::first-line

Solo la primera línea del párrafo cambia de estilo, y se adapta sola si cambias el tamaño de la ventana, porque depende del texto que cabe en ella.

::before y ::after

Producto destacado

Los símbolos y la etiqueta los agrega CSS con content.
::selection y ::placeholder

Selecciona este texto con el mouse: el color de selección lo define ::selection.

¿Cómo no confundirlas?

  • Pseudo clase (:): depende del estado del elemento. Pregunta "¿en qué situación está?".
  • Pseudo elemento (::): elige una parte del elemento o crea una nueva. Pregunta "¿qué parte quiero modificar?".
  • En especificidad, una pseudo clase pesa como una clase (0,0,0,1,0) y un pseudo elemento como un elemento (0,0,0,0,1).
