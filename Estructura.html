Estructura y Sintaxis de CSS

Aprende los fundamentos para dar estilo a una página web

¿Qué es CSS?

CSS (Cascading Style Sheets, u Hojas de Estilo en Cascada) es el lenguaje que controla cómo se ve una página web: colores, tipografías, tamaños, espacios y posiciones.

HTML define el contenido y la estructura; CSS define su apariencia.

Comentarios

Sirven para explicar el código y el navegador los ignora. Se escriben entre /* y */. 

/* Estilos del encabezado */
h1 {
    color: blue; /* azul */
}

Anatomía de una regla CSS

h1 {
    color: blue;
    font-size: 32px;
}
Parte En el ejemplo Qué hace
Selector h1 Indica a qué elementos se aplica la regla.
Bloque de declaraciones { ... } Agrupa todos los estilos de la regla.
Propiedad color Lo que se quiere cambiar.
Valor blue Cómo se quiere cambiar.

Cada declaración separa la propiedad y el valor con dos puntos y termina con punto y coma.

Tres formas de agregar CSS

1. En línea: con el atributo style.

<h1 style="color: blue;">Hola</h1>

2. Interno: dentro de <style> en el <head>.

<style>
    h1 { color: blue; }
</style>

3. Externo (la más recomendada): en un archivo .css.

<link rel="stylesheet" href="estilos.css">

Selectores básicos

Selector Ejemplo Elige
Universal * Todos los elementos
Elemento p Todas las etiquetas <p>
Clase .texto Elementos con class="texto"
ID #titulo El elemento con id="titulo"
Agrupado h1, h2 Varios a la vez
Descendiente nav a Los <a> dentro de un <nav>

Errores comunes

  • Olvidar el punto y coma ; al final de una declaración.
  • Olvidar cerrar la llave }.
  • Escribir mal una propiedad, por ejemplo colour en vez de color.
  • Olvidar el punto . de las clases o el # de los IDs.

CSS no muestra errores: ignora la línea mal escrita. Si un estilo no se aplica, revisa primero la sintaxis.

Ejemplo completo

<!-- HTML -->
<h1 class="titulo">Mi primera página</h1>
<p>Aprendiendo CSS.</p>

/* CSS */
.titulo {
    color: blue;
    text-align: center;
}

p {
    font-size: 18px;
}
